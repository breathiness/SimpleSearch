# 自定义站点

> 返回 [Wiki 首页](Home) · 仓库里的完整字段说明：[docs/custom-sites.md](https://github.com/breathiness/SimpleSearch/blob/main/docs/custom-sites.md)

加站点有两种方式：**设置里可视化添加**（推荐，只影响你自己的浏览器，不改代码）或**改 `assets/js/sites.js` 进仓库内置**（需要重新构建，所有访问者都能看到）。

## 方式一：在界面添加（推荐）

1. 右上角设置 → **我的站点** → 管理 → **新增站点**。
2. 填表：
   - **名称**：按钮上显示的文字（1–24 字符）
   - **首页网址**：留空关键词时直接打开，必须 `https://`
   - **搜索模板**：用 `{q}` 表示关键词，例如 `https://example.com/search?q={q}`，必须 `https://` 且含 `{q}`
   - **分类**：技术开发 / 社区问答 / 影音游戏 / 购物 / 素材资讯（五选一）
   - **关键词**：空格分隔，可选（用于联想和 `!bang`，最多 8 个）
   - **放进「常用」**：勾选后同时出现在默认视图
3. 保存后按钮**立刻**出现在对应分类（勾了常用就同时进常用视图），不用 `npm run build`；刷新/重开页面都还在。
4. 列表里可以继续编辑 / 删除；站点 id 自动生成（`custom-…`），**id 和关键词自动成为 `!bang` token**（例如 `!custom-1 词`）。
5. 最多 100 个自定义站点；不合法会提示原因、不会写入。

自定义站点与常用顺序都存在浏览器本地（`ss.customSites` / `ss.order`），不会上传。设置里的**配置导出 / 导入**可以把它们和主题、搜索引擎等一起备份成 `simplesearch-config.json`，换电脑时导入即可。

> 自定义站点不选图标时显示名称首字符（monogram）；数据里也可以带 `icon: 'cat-tech'` 复用分类图标。

## 方式二：写进仓库（内置站点）

想让站点成为**所有访问者**都能看到的默认站点，才需要改 `assets/js/sites.js` 并重新构建。`npm run build` 会生成五个产物：`index.html`、`SimpleSearch.html`、两个重定向壳、`sw.js`，**不用手改 HTML**。

```js
// assets/js/sites.js —— SS.sites 数组里追加一条
{
  id: 'example',                                // 唯一、小写、只含 [a-z0-9-]
  label: '示例站点',                             // 按钮文字
  home: 'https://example.com',                  // 空关键词时打开
  search: 'https://example.com/search?q={q}',   // 站内搜索，必须有 {q}
  keywords: ['示例', 'demo'],                    // 可选：联想 + !bang token
  group: 'tech',                                // 必填：见 SS.siteGroups
  icon: 'cat-tech',                             // 可选：复用分类图标 / 专属 symbol 名
  featured: true,                               // 可选：true 才进「常用」
}
```

然后：

```bash
npm run build     # 重新生成 5 个产物
npm test          # 可选：单元测试
npm run validate  # 可选：静态检查 + 产物是否最新
```

### 分类与图标

- **分类必填**：`group` 取值来自 `SS.siteGroups`：`tech` 技术开发、`community` 社区问答、`media` 影音游戏、`shopping` 购物、`content` 素材资讯；导航顺序就是数组顺序。
- **加新分类**：在 `SS.siteGroups` 追加 `{ id: 'xxx', label: '显示名' }`，再让相关站点指过去。站点缺 `group` 或值不在表里时 build 直接失败。
- **图标三级解析**：站点专属 symbol（`scripts/icons.mjs`）→ `icon` 指定的 symbol（如 `cat-tech`）→ 首字符 monogram。
- **常用标记**：新站点默认只出现在分类里；加 `featured: true` 才进「常用」（内置 11 站都有）。

### 删除站点

- 界面添加的：在「我的站点」列表里点「删除」。
- 仓库内置的：从 `SS.sites` 里删掉对象，再 `npm run build`。

### 注意事项

- `search` 里的 `{q}` **原样写**，编码交给代码（`search.js` 做 `encodeURIComponent`）；不要自己写 `%20` 或 `+`。
- `home` / `search` 必须 `https://`；`search` 必须含 `{q}`，否则 build 报错。
- 只改 `sites.js` 忘了 `npm run build` → 提交的 HTML 与数据对不上，CI 的产物漂移检查会拦住。
- 新站点的 `id` / `keywords` 自动成为 `!bang` token，无需额外注册。
- 内置站点的 **id 和它们之间的相对顺序**由 `tests/sites.test.mjs` 固定；新增站点不会让测试变红，删内置站点才会。
- 只是自己用的话，**优先用界面添加**；改 `sites.js` 只适合要提交进仓库当内置站点的情况。
