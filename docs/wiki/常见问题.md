# 常见问题

> 返回 [Wiki 首页](Home)

<details>
<summary><b>1. 为什么不把简单搜索设为浏览器默认搜索引擎（<code>?q=%s</code> 自动提交）？</b></summary>

这是**有意排除**的需求。本项目希望「搜索始终由你触发」：`?q=` 只预填、不自动提交，避免打开页面就被当成搜索引擎入口。想一键搜索可以用 README 里的书签小工具。

</details>

<details>
<summary><b>2. 我的数据（主题、历史、自定义站点）存在哪？会上传吗？</b></summary>

只存在浏览器本地 `localStorage`，共 7 个键：`ss.theme`、`ss.color`、`ss.engine`、`ss.history`、`ss.remote`、`ss.customSites`、`ss.order`。不会上传、不含账号或身份信息。清理站点数据即可全部删除；「我的站点」里的导出 / 导入只读写本地 JSON 文件。

</details>

<details>
<summary><b>3. 怎么添加自己的网站？</b></summary>

设置 → **我的站点** → 管理 → 新增站点，填名称 / 首页 / 搜索模板（含 `{q}`）/ 分类 / 关键词即可，存本地、不用重新构建、刷新还在（最多 100 个）。想让所有访问者都看到才需要改仓库里的 `sites.js` 并 `npm run build`。详见 [自定义站点](自定义站点)。

</details>

<details>
<summary><b>4. 单文件便携版和多文件版有什么区别？</b></summary>

- `SimpleSearch.html`：CSS/JS/图标全部内联，**零外部请求**，双击即用、可以只发一个文件给别人；但没有 PWA 安装 / 离线缓存（Service Worker 必须是独立文件），改一个字整页重下。
- `index.html`（线上版）：17 个请求、零第三方，支持 PWA 安装与断网刷新，CSS/JS 可分别缓存。

</details>

<details>
<summary><b>5. 断网还能用吗？</b></summary>

- 本地双击：本来就不需要网络。
- 线上版装过 PWA（Chrome/Edge 地址栏「安装」）后：断网刷新也能打开，Service Worker 预缓存了全部静态资源。
- 联网联想在断网 / 超时（700ms）时自动退回本地联想，不影响搜索。设置里关掉联网联想后完全离线。

</details>

<details>
<summary><b>6. 「安装到桌面」按钮在哪里？</b></summary>

用 Chrome / Edge 打开在线版（`index.html` 多文件版）时，只要浏览器认为满足安装条件，右上角设置面板里就会出现「安装到桌面」行，点「安装」即可；地址栏右侧的安装图标也可以。以下情况该行不会出现（属预期）：已经安装过、用的是单文件便携版（没有 Service Worker）、`file://` 本地双击打开、或浏览器不支持 PWA。安装后如果后台更新了新版本，底部会弹「新版本已就绪」，点「刷新」立即更新，点「稍后」本次不再提示。

</details>

<details>
<summary><b>7. 输入关键词时会把内容发给谁？</b></summary>

只在**联网联想开启**（默认开启）时把关键词发给百度（`suggestion.baidu.com` JSONP）。在设置里关掉「联网联想」后不再有任何第三方请求。搜索本身是浏览器原生表单提交到目标站点，不经过中间服务器。

</details>

<details>
<summary><b>8. 站点图标为什么没有任何图片请求？</b></summary>

所有图标都是构建时内联进 HTML 的 SVG sprite（`<symbol>` + `<use>`），浏览器不下载图片；图标数据在 `scripts/icons.mjs`，只在 `npm run build` 时被读取。细节见 [技术实现 § 站点图标](技术实现#站点图标内联-svg-sprite零图片请求)。

</details>

<details>
<summary><b>9. 页面更新了但我看到的还是旧版？</b></summary>

线上版会走 Service Worker 缓存，但 `sw.js` 每次发版都带新版本号，`activate` 时会清掉旧缓存。如果仍看到旧样式：刷新一次（或关掉标签页重开）；开发时也可以在 DevTools → Application → Service Workers 里 Unregister 后硬刷新。

</details>

<details>
<summary><b>10. 收藏的分类视图 / 深链会不会自动搜索？</b></summary>

不会。`?cat=` 只选分类、`?q=` 只预填、`?site=` 只预选并聚焦按钮，都不会自动提交或跳转。详见 [功能详解 § 深链](功能详解#深链可收藏--分享)。

</details>
