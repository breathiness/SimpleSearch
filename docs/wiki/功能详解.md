# 功能详解

> 返回 [Wiki 首页](Home)

## 基本操作

| 操作 | 结果 |
|---|---|
| 输入关键词 + 回车 / 点「搜索」 | 用当前选择的搜索引擎（默认 Bing）搜索 |
| 输入框留空 + 点站点按钮 | 打开该网站首页 |
| 输入关键词 + 点站点按钮 | 跳到该网站的搜索结果页 |
| `Ctrl` / `⌘` / `Alt` + 点站点按钮 | 在新标签页打开 |

## `!bang` 站点快捷搜索

输入框里用 `!` 开头可以直接在某个站点里搜，不用先点按钮。

| 输入 | 效果 |
|---|---|
| `!gh rust` | 在 GitHub 里搜 rust |
| `!so rust` | 在 StackOverflow 里搜 rust |
| `!youtube cats` | 在 YouTube 里搜 cats |
| `!b站 视频` | 在哔哩哔哩里搜「视频」 |
| `!淘宝 键盘` | 在淘宝里搜「键盘」 |
| `!gh` | 不带词：直接打开 GitHub 首页 |
| `!nope 东西` | 未知 token：当普通搜索，用当前搜索引擎 |

规则：

- 语法是 `!<token> [搜索词]`；`<token>` 匹配**站点 id** 或该站的 **keywords**（大小写不敏感，支持中文），只认第一个 token。
- keyword 全表共享，重复时按注册表顺序命中靠前的内置站点：`!购物` → 淘宝、`!视频` → 哔哩哔哩。
- 输入合法 bang 时，联想列表第一项会变成「在 GitHub 搜索：rust」，选中即可直达。

## 分类导航

左侧导航的组标题是「站点分类」，下面是竖排分类项：「常用」「技术开发」「社区问答」「影音游戏」「购物」「素材资讯」，每项带一个小图标。

- **常用**（默认视图）：只显示最早内置的 11 个常用站点。
- **点某个分类**：显示该分类全部站点（技术开发 7、社区问答 6、影音游戏 8、购物 6、素材资讯 6，共 33 个内置站点）。
- 内容区卡片标题跟着变：常用 →「常用网站」，分类 → 分类名。
- 地址栏同步 `?cat=<id>`（回到常用时去掉），分类视图可收藏；刷新以 URL 为准。
- 无 JS 时默认只显示 11 个常用站（其余按钮构建时就是 `hidden`），不会出现「按钮铺满但点不动」。
- 小屏（<960px）导航变左侧抽屉：点汉堡打开，点遮罩、`Esc`、或选中分类后自动收起。

## 内置站点（33 个）

| 分类 | 站点 |
|---|---|
| 技术开发（7） | GitHub、ArchWiki、StackOverflow、MDN、Gitee、npm、掘金 |
| 社区问答（6） | 知乎、百度贴吧、豆瓣、微博、V2EX、Reddit |
| 影音游戏（8） | 哔哩哔哩、Steam、萌娘百科、YouTube、抖音、爱奇艺、腾讯视频、Twitch |
| 购物（6） | 淘宝、京东、天猫、拼多多、闲鱼、亚马逊 |

除这 33 个内置站点，还可以在设置「我的站点」里加自己的站点（存本地，最多 100 个），同样自动进分类和 `!bang`——见 [自定义站点](自定义站点)。

## 深链（可收藏 / 分享）

URL 参数**只预填和预选，不会自动跳转或提交**：

| 参数 | 效果 |
|---|---|
| `?cat=tech` | 进入就展开「技术开发」分类（该分类全部站点），等价于点一下左侧分类项 |
| `?cat=all` / 不带 `cat` | 常用视图（11 个常用站） |
| `?q=rust` | 预填 `rust` 并聚焦搜索框，**不自动搜索** |
| `?site=bilibili` | 选中哔哩哔哩所属分类并把焦点移到它的按钮上，**不打开网站** |

可以组合，例如 `?cat=tech&q=rust`；处理顺序是 cat → site → q，保证最后焦点落在搜索框。

本项目**不做**「把本站设为浏览器默认搜索引擎」的 `?q=%s` 自动提交——搜索始终由你按回车或点按钮触发。

## 命令面板（`Ctrl` / `⌘` + `K`）

不想用鼠标时，按 `Ctrl` / `⌘` + `K`（在输入框里也生效）打开命令面板，一个框搞定三件事：

| 输入 | 结果 |
|---|---|
| 关键词（如 `git`） | 第一组「搜索：git」→ 用当前搜索引擎搜；下面列出匹配的站点 |
| 站点名 / id / 关键词（如 `gh`、`GitHub`） | 站点组里选中回车直接打开该站首页（想站内搜：输入关键词后点站点按钮，或选「搜索：<词>」） |
| 命令名（如 `主题`、`English`、`历史`） | 命令组里执行对应操作 |

- 结果分「搜索：<词>」「站点」「命令」三组；站点按 `label` / `id` / `keywords` 做子序列模糊匹配（`gh` 能命中 GitHub），短词前缀优先。
- 键盘：`↑` / `↓` 移动、`Enter` 执行、`Esc` 关闭并归还焦点；鼠标点击也能执行。
- 可用命令：打开设置、我的站点、常用排序、切换主题模式、切换主题色、切换搜索引擎、切换语言、清空搜索历史、联网联想开关。
- 面板打开时不会自动搜索，只有你按 `Enter` 才会执行。

## 英文界面

设置 →「语言」三选一：**跟随系统 / 中文 / English**。

- 选 English 后，导航、设置、卡片标题、对话框、命令面板、状态提示等界面文案切到英文，`<html lang="en">` 同步更新；刷新后保持。
- 也可以用深链 `?lang=en`（或 `zh`）直接切；读取后会把参数持久化并从地址栏去掉，方便分享。
- 选「跟随系统」时按浏览器语言判断：`zh` 开头用中文，否则英文；此时不写 `localStorage`（`ss.lang` 不存在）。
- 已知限制：界面短文案已翻译；**日期、数字不做本地化**（例如历史条数、版本号等仍按浏览器/数字格式显示）。

## 书签小工具（把选中文字带到搜索框）

在任意网页选中一段文字，点一下书签，就能打开 SimpleSearch 并把这段文字预填进搜索框（**只预填，不自动搜索**）。

1. 打开「书签管理器」（Windows/Linux `Ctrl+Shift+O`，macOS `⌘+Option+B`）；
2. 新建书签，名称随意（例如「搜一下」）；
3. 「网址 / URL」填下面整段代码（是一行，直接复制）：

```text
javascript:(function(){var s=String(window.getSelection());if(s)window.open('https://breathiness.github.io/SimpleSearch/?q='+encodeURIComponent(s.trim()),'_blank')})()
```

4. 保存后，在任意网页选中文字点这个书签即可。

小提示：

- 浏览器把 `javascript:` 前缀过滤掉时，手动补回开头再保存。
- 这段代码只是拼 `?q=<选中文字>` 并在新标签页打开，**不会自动提交搜索**——和「不做默认搜索引擎自动提交」不冲突。

## 设置面板

右上角齿轮从右侧滑出设置抽屉：

- **主题模式**：跟随系统 / 浅色 / 深色。选「跟随系统」会删掉 `ss.theme` 并实时跟随系统；选浅色 / 深色才记住。首屏按「`?theme=` 老参数 → 显式选择 → 系统偏好 → 浅色」决定，不闪白/闪黑。
- **搜索引擎**：Bing / Google / DuckDuckGo / 百度，默认 Bing，选择记住（`ss.engine`）；表单提交地址与参数名自动适配（百度用 `wd`），联想首项文案跟着变。
- **主题色**：19 个 MDUI 主色色块（默认靛蓝），点一下整站换色并记住（`ss.color`）；只是 CSS 变量，零请求。浅色主题用 700 档、深色用 200 档保证对比度，浅色系主色自动用深色文字。
- **联网联想**总开关（默认开启）。
- **联想源**：`百度` / `自定义` / `关闭` 三选一。选「自定义」时填一个带 `{q}` 的接口地址（例如 `https://example.com/suggest?q={q}`），返回 `["词"]`、`{"s":["词"]}` 或 `{"data":["词"]}` 都能解析；700ms 超时或失败自动退回本地联想。选「关闭」后不发任何远程请求。
- **语言**：跟随系统 / 中文 / English；也可用 `?lang=en`，详见上面的「英文界面」。
- **搜索历史**：显示条数 + 「清空」按钮（0 条时禁用）；联想列表里每条历史右侧有 `✕` 可单删，键盘高亮后按 `Delete` 也能删。
- **我的站点**：「管理」打开对话框，可视化新增 / 编辑 / 删除（存 `ss.customSites`，不改代码，最多 100 个）。
- **常用排序**：「调整」打开排序对话框，↑ / ↓ / 置顶（存 `ss.order`）。
- **配置导入 / 导出**：导出 `simplesearch-config.json`（自定义站点 + 排序 + 主题模式 / 主题色 / 搜索引擎 / 联网联想）；导入校验格式，非法整包拒绝（超过 1 MB 直接拒绝）。
- **键盘快捷键**：「查看」或按 `?` 打开说明对话框（含 `Ctrl` / `⌘` + `K`）。
- GitHub 仓库链接、底部版本号。

点关闭按钮、点遮罩或按 `Esc` 收起；焦点进入面板、关闭后回到设置按钮；分类抽屉、设置抽屉、快捷键对话框、「我的站点 / 常用排序」共用一层遮罩，同一时刻只开一个。

## 键盘操作

| 按键 | 作用 |
|---|---|
| `/` | 聚焦搜索框 |
| `↑` / `↓` | 在联想列表里上下移动 |
| `Enter` | 采用高亮联想项；无高亮时普通提交 |
| `Esc` | 关闭联想列表、分类抽屉、设置面板或对话框 |
| `Delete` | 删除高亮的历史联想项 |
| `Tab` | 移出搜索框并收起联想 |
| `?` | 打开快捷键说明（焦点不在输入框时） |
| `Ctrl` / `⌘` + `K` | 打开命令面板（搜词 / 跳站点 / 跑命令） |
| `Ctrl` / `⌘` / `Alt` + 点站点按钮 | 新标签页打开 |

## 小功能说明

- **清除按钮**：输入框有内容时右侧出现 `✕`，点一下清空并保持输入状态。
- **关键词联想**：最多 8 条。本地部分（当前引擎提示、匹配站点、历史词）永远可用、断网也在；开启联网联想后百度词排在本地点匹配之后并标注「百度」。
- **可配置联想源**：设置里可选百度 / 自定义 `{q}` 接口 / 关闭；自定义源返回 `["词"]`、`{"s":["词"]}`、`{"data":["词"]}` 三种形状都支持，700ms 超时或失败静默回退本地；选「关闭」后零远程请求。
- **搜索历史**：最近 10 条，新的在前、自动去重；作为联想项出现，可在设置里看条数 / 清空 / 单删。
- **可访问性**：联想列表有 `listbox` / `option` 语义与 `aria-activedescendant`；有 skip link；焦点轮廓与 `prefers-reduced-motion` 都处理了。
